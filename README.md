See https://youtu.be/2Bxh5FNGznQ for a full walk through on spinning up this full-stack Php web app with MySql and phpMySql

Requirements: 
* Docker 

To run this code, run command: `docker-compose up` from the shell within the directory of this project after cloning it. 

## Aufbau eines Zielsystems
- Nutzer kann Ziele für einen Zeitraum setzen (zB täglich, wöchentlich, monatlich)
- Im meine Ziele Tab soll der Progress zu seinen Zielen aufgeführt werden
- mögliche Zielkategorien / Beispiele
  - x Liegestützen pro Tag
  - Bench Press mit 80kg in einem Monat
  - diesen Monat jeden Tag trainieren (-> Habbit Tracker läuft bei default mit)
  - jeden Mittwoch workout x abschließen
